# Activity: Ask for a Useful Dinner Plan

[⬅ Back to Activities](README.md)

## The scenario

“What should I cook?” leaves out most of what an assistant needs to know. Practice the section's **Goal + Context + Constraints + Output + Check** pattern, then improve the request after reading the answer.

## Before you ask

Predict one way an assistant could misunderstand “What should I cook?”

## Copy this into your AI assistant

```text
My goal is to make dinner for two tonight.
Context: I have pasta, canned tomatoes, an onion, frozen peas, one pot, and one pan.
Constraints: I have 30 minutes. Use only these ingredients unless you clearly label an optional addition. Keep the steps suitable for a beginner.
Please produce: Two meal options. For each, give an estimated time, a short ingredient list, and numbered steps.
Help me check it by: Pointing out any missing information, uncertain timing, or step I should verify in my kitchen. Do not invent ingredients I said I have.
```

## Do the activity

1. Mark where the prompt gives the goal, context, constraints, output, and check.
2. Read the response. Does either option assume an ingredient, tool, or skill you did not provide?
3. Add one real constraint, such as “no oven” or “I need leftovers,” and send a follow-up request for a revised plan.
4. Compare the two responses. Identify one change caused by the new context.

## Check your understanding

What information made the answer more useful? What would you ask next if the answer still did not fit? A detailed prompt helps, but you still need to inspect the result.
