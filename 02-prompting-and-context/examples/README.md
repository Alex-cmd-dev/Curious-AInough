## Try it

**Vague version:** "Explain photosynthesis."

**Applying Goal + Context + Constraints + Output + Check:**

> "Help me understand photosynthesis for a first-year biology quiz. I know the basic equation but struggle with the light-dependent reactions. Explain them in five short steps, then ask me two questions. Flag any simplifications."

Compare the two. The second version tells the assistant *why* you're asking (quiz prep), *what you already know* (the equation), *what to skip* (don't re-explain the basics), *the output shape* (five steps, then two questions), and *how to handle uncertainty* (flag simplifications).
