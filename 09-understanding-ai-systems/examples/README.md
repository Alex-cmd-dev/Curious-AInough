# 📎 Examples: Understanding AI Systems

[⬅ Back to Understanding AI Systems](../README.md)

The same permissions checklist applies wherever a tool, skill, or MCP server touches real data, across every field.

### 🔬 Science & Engineering

**Scenario:** A lab wants to connect an AI assistant to its instrument database via MCP so it can pull recent readings automatically.

> [!TIP]
> Before connecting it: Who built this MCP server? Can it only read data, or can it also delete or overwrite readings? Does it need write access at all for what the lab wants to do?

### 📜 Humanities & History

**Scenario:** A research assistant skill is supposed to auto-format citations from an archive's database.

> [!TIP]
> Before installing it: Does the skill only read citation metadata, or does it also submit data back to the archive? What happens if it misformats a citation, would you catch it before it's published?

### 💼 Business & Entrepreneurship

**Scenario:** A small business wants an agent connected to its customer database (CRM) to draft follow-up emails automatically.

> [!TIP]
> Before granting access: Can the agent only read customer records, or can it also send emails and edit records? What's the blast radius if it drafts (or sends) something wrong to a real customer?

### 🎨 Arts & Design

**Scenario:** An artist wants to use a new image-generation extension that asks for access to their entire cloud photo library.

> [!TIP]
> Before granting it: Does it need the whole library, or just the folder of reference images? What does the provider do with uploaded images? Is there a lower-access option?

### 🌍 Everyday Life & Community

**Scenario:** Installing a new MCP server, skill, or extension for a personal smart-home or scheduling assistant.

> [!TIP]
> 1. Who publishes this, and is that source trustworthy?
> 2. What can it actually see (files, accounts, the internet)?
> 3. What can it actually do (read only, or also write/send/delete)?
> 4. Does it need all of that access for what I want it to do?
> 5. Would I be comfortable if it failed or misbehaved on my most sensitive file or account?
>
> If you can't answer all five, don't connect it to anything sensitive yet.
