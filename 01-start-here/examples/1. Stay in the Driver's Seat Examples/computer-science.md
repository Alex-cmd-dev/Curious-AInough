# Computer Science: Stay in the Driver's Seat

[Back to examples](../README.md)

**Remember:** You set the goal. AI assists. You decide.

## Goal
Find out why my program crashes when the input box is empty.

## The five-step loop
1. **Define the goal:** Find out why my program crashes when the input box is empty.
2. **Give context:** Paste the error message and the few lines of code involved. Remove passwords and keys.
3. **Explore:** Ask AI for likely causes and two different ways to fix it.
4. **Check:** Run the program with empty and normal input. Read the fix line by line and check any function it uses in the official docs.
5. **Decide:** Choose the fix, add a test for it, and be able to explain it in your own words.

## Why it fits computer science
Code that runs is not the same as code that is correct. You still own what you submit.

## Try it yourself
Write one goal from your own classes or life. What will you check before you trust the answer?
