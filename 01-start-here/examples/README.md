## Try it

> "I need to choose a topic for a five-minute class talk. I enjoy biology and music. Suggest three topics, what I could explain in each, and what I should verify before choosing."

Notice what this prompt does: it states a goal (choose a topic), gives context (interests, time limit), and asks for something to check afterward — the four moving pieces of the five-step loop in one message.
