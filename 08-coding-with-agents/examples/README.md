## Try it

> [!TIP]
> "Find why this test fails. Explain the cause, make the smallest useful fix, run the relevant tests, and summarize the files you changed."
>
> Notice this asks for the smallest fix (not a rewrite), and requires the agent to run tests and report exactly what changed, so you can review a small, verifiable diff instead of a large, unreviewable one.
