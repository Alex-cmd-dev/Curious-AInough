# 📎 Examples: Coding With Agents

[⬅ Back to Coding With Agents](../README.md)

Coding agents show up in more than just software projects. Applying the safe workflow across different fields.

### 🔬 Science & Engineering

> [!TIP]
> "This Python script for analyzing our lab's sensor data throws an error on the last dataset. Find why the test fails, explain the cause, make the smallest useful fix, run the relevant tests, and summarize the files you changed."

### 📜 Humanities & History

> [!TIP]
> "I have a script that's supposed to pull dates and names out of 200 digitized letters for my research, but it's missing some entries. Inspect it, propose the smallest fix, run it on a sample of 10 letters, and show me what changed before running it on everything."

### 💼 Business & Entrepreneurship

> [!TIP]
> "I have a small internal tool that generates weekly sales reports from a spreadsheet. Add a new column for month-over-month change. Show me the plan before you touch the code, and tell me which files will change."

### 🎨 Arts & Design

> [!TIP]
> "This generative art script is supposed to draw a spiral pattern but the colors aren't cycling correctly. Explain what's wrong, make the smallest fix, and show me a before/after so I can see what changed visually."

### 🌍 Everyday Life & Community

> [!TIP]
> "I have a small script that reminds me and my roommates whose turn it is to take out the trash, but it skipped a week. Find the bug, explain the cause, fix it, and test it against the last three weeks of data."
