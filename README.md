# Elevate Your Thinking

**Using AI to Learn, Question, Create, and Grow**

This is the companion resource repository for the Elevate Your Thinking student workshop. It contains the deeper explanations, examples, prompts, resources, optional technical material, and current links that would overload the 60-minute presentation.

## Core idea

Use AI to become more capable — not more dependent.

The student sets the goal, supplies judgment, checks important work, and owns the final decision.

## Keep current

Tool offers, pricing, eligibility, quotas, security guidance, and official documentation change over time. Verify current information from official sources before presenting it to students.
