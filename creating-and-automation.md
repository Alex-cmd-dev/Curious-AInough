# Creating & Automation

## Core idea

Start from a real problem or repetitive task. Break it into steps, decide where AI can help, and keep human review where it matters.

## Workflow

1. Define the useful outcome.
2. Map the current process from input to result.
3. Identify repetitive, language-heavy, or pattern-based steps.
4. Decide what AI can assist with and what must stay human-owned.
5. Build the smallest workable version.
6. Test normal cases, edge cases, and failure cases.
7. Review the result and improve the process.

## Human review belongs where

Accuracy, safety, privacy, fairness, quality, consent, money, reputation, or other people’s opportunities are affected.

## Ownership test

You should understand the result well enough to inspect it, question it, improve it, explain it, and take responsibility for using it.
