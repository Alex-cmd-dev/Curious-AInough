## Try it

> [!TIP]
> "I want to run a campus repair event. Suggest three formats, then challenge each one on space, volunteers, accessibility, and cost. Which questions should I answer before deciding?"
>
> Notice the two-part structure: first generate options, then deliberately ask for pushback on each one along specific dimensions that matter for the decision.
