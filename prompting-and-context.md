# Prompting & Context

## Purpose

Clear prompting is clear assignment design. A useful request gives the tool enough direction to produce something you can inspect and improve.

## Prompt pattern

**Goal + Context + Constraints + Output + Check**

### Goal

State what you are trying to accomplish.

### Context

Include relevant background, audience, starting point, and what you have already tried.

### Constraints

Specify limits such as length, format, tone, deadline, sources, level, tools, or what the response must not do.

### Output

Describe the form you want: outline, examples, questions, table, critique, draft, checklist, or explanation.

### Check

Ask for assumptions, uncertainties, evidence, tests, or questions you should answer next.

## Reusable pattern

```text
My goal is:
Context you need:
Constraints:
Please produce:
Help me check it by:
```

## Practice

Take a vague request and add one detail from each part of the pattern. Compare the first and second responses, then decide which details mattered.
