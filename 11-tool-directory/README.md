# 🧰 11. Tool Directory: Find a Tool for the Task

[⬅ Back to overview](../README.md) · [⬅ Previous: Understanding AI Systems](../10-understanding-ai-systems/README.md)

Use this page to find a starting point for a task. It is a short directory, not a ranking: tools change, and the best fit depends on what you need, what access you have, and what you are comfortable sharing.

## Find a tool by task

| If you want to... | Tools to explore | Check before you rely on it |
| --- | --- | --- |
| Ask questions, draft, learn, or work with files | General assistants such as [ChatGPT](https://chatgpt.com/), [Claude](https://claude.ai/), [Gemini](https://gemini.google.com/), or [Grok](https://grok.com/) | Compare the same task in a couple of tools. Check file access, data controls, usage limits, and whether the feature you need is available on your account. See [AI and Large Language Models](../01-ai-and-llms/README.md) for a provider comparison. |
| Research a question or find sources | [Perplexity](https://www.perplexity.ai/) or a general assistant with web search | Open the original sources. Check the date, author, and whether each source actually supports the answer. |
| Ask questions about a set of documents | [NotebookLM](https://notebooklm.google.com/) | Check which sources it used and verify important claims in the documents themselves. |
| Write or understand code in a project | [Codex](https://developers.openai.com/codex/), [Claude Code](https://docs.anthropic.com/en/docs/claude-code/overview), [GitHub Copilot](https://github.com/features/copilot), or [Cursor](https://cursor.com/) | Check what files and commands the tool can access, how changes are reviewed, and whether your code can be sent to the provider. See [Coding With Agents](../09-coding-with-agents/README.md). |
| Run a repeated task on a schedule or trigger | Scheduled features in [ChatGPT](https://help.openai.com/en/articles/10291617-scheduled-tasks-in-chatgpt), [Gemini](https://support.google.com/gemini/answer/16316416), or [Claude Cowork](https://www.anthropic.com/news/claude-for-teachers), where available | Check what starts the task, what information and connected apps it can use, what actions it can take, and how to pause it. Start with a draft or notification you can review. See [AI Automation](../08-ai-automation/README.md). |

These are examples to help you start looking. They are not endorsements or guarantees that a tool will suit your task.

## Students: look for education offers

Some providers offer free or discounted plans to students. Eligibility can depend on your country, school, enrollment status, and verification. Offers can expire or renew at the regular price, so confirm the current terms before signing up.

| Offer | What it may include | Check the terms |
| --- | --- | --- |
| [Google AI Pro student offer](https://one.google.com/about/google-ai-plans/) | Google advertises one year free for eligible students in supported regions. | Confirm current availability, eligibility, claim deadline, renewal price, and payment requirements. School-issued accounts may not qualify. |
| [GitHub Copilot Student](https://docs.github.com/en/copilot/how-tos/copilot-on-github/set-up-copilot/enable-copilot/set-up-for-students) | Verified GitHub Education students can access the Copilot Student plan at no charge. | Apply for GitHub Education and activate the benefit. Check the current features and verification requirements. |
| [Perplexity Education Pro](https://www.perplexity.ai/help-center/en/articles/12590157-what-is-education-pro) | A discounted plan for verified students and educators. | This is a discount, not a free subscription. Confirm the current price and renewal terms. |

## Before you sign up

- **Access:** Is the tool available where you live, and does your account or school qualify?
- **Cost:** Is it free, a trial, a discount, or credits? When does it renew, expire, or start charging?
- **Limits:** Are there usage caps, feature restrictions, or quotas?
- **Privacy:** What information will the tool receive, and can you control how it is used?
- **Actions:** Can it only prepare a draft, or can it send messages, change files, or take other actions?

If the tool handles sensitive information or can act on your behalf, review its permissions and data terms before connecting it. For recurring tasks, try one run and inspect the result before relying on future runs.

## Suggest a directory entry

When adding a tool, link to its official page, say what task it helps with, and include a meaningful limitation. Check access, location, limits, costs, and permissions; these details change.
