## Try it

> [!TIP]
> Say you need to refactor a small coding project for a class assignment. Before picking a tool, answer:
>
> 1. What's the actual task? (writing code vs. explaining a concept vs. drafting a paper)
> 2. Which tool in the table above is built for that?
> 3. Is the "free" access a free tier, a trial, or a student offer with an expiration date?
> 4. What happens to my access (and my work) if I don't renew or requalify?
>
> For a coding assignment, that usually points to [GitHub Copilot Student](https://github.com/education/students) or [Claude Code](https://docs.anthropic.com/en/docs/claude-code/getting-started) rather than a general chat assistant. Check the current table for terms.
