# 📎 Examples: Tool Directory

[⬅ Back to Tool Directory](../README.md)

Matching the tool to the task, across different fields.

### 🔬 Science & Engineering

**Task:** Analyzing a dataset and writing a small script to chart the results.

> [!TIP]
> Ask: Do I need code help specifically, or general explanation? A coding-focused tool ([GitHub Copilot Student](https://github.com/education/students), [Claude Code](https://docs.anthropic.com/en/docs/claude-code/getting-started)) fits better than a general chat assistant here, check current terms in the table above.

### 📜 Humanities & History

**Task:** Drafting and revising a long research paper with many sources.

> [!TIP]
> Ask: Do I mainly need writing and reasoning help with large documents? A general assistant like [ChatGPT](https://help.openai.com/en/articles/20001493-chatgpt-back-to-school-offer-for-students) or [Claude](https://www.anthropic.com/pricing) is usually the better starting point than a coding-specific tool.

### 💼 Business & Entrepreneurship

**Task:** Building a pitch deck and a simple financial model.

> [!TIP]
> Ask: Is this drafting and analysis, not code? A general assistant covers the writing and math reasoning; check whether your school's [GitHub Education benefits](https://education.github.com/pack) or other student offers include any relevant extras before paying for a new tool.

### 🎨 Arts & Design

**Task:** Refining a creative coding sketch (generative art) for a class show.

> [!TIP]
> Ask: Is the bottleneck the code or the idea? If it's code, a coding-agent tool fits; if it's the concept, a general assistant for brainstorming (see [💡 Brainstorming & Curiosity](../../05-brainstorming-and-curiosity/README.md)) is the better fit first.

### 🌍 Everyday Life & Community

**Task:** General personal use: planning, drafting, explaining things.

> [!TIP]
> Say you need to refactor a small coding project for a class assignment instead. Before picking a tool, answer:
>
> 1. What's the actual task? (writing code vs. explaining a concept vs. drafting a paper)
> 2. Which tool in the table above is built for that?
> 3. Is the "free" access a free tier, a trial, or a student offer with an expiration date?
> 4. What happens to my access (and my work) if I don't renew or requalify?
